# Installation

## From disk (any project)
1. Open **Window > Package Manager**.
2. Click **+ > Add package from disk...**
3. Select the `package.json` inside the `com.tools.android-icon-generator` folder.

## Embedded
Copy the `com.tools.android-icon-generator` folder into your project's `Packages/` folder.

## Verify
**Tools > Android Icon Generator** should appear in the menu. The package has no dependencies other than the built-in Image Conversion module.

## Optional sample
In Package Manager, select the package, open **Samples** and import **Example Logo**.
